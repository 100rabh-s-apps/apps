# Bird Quiz

This is a simple quiz game about birds.

## How to play

1.  Download the missing files:
    *   **Background Image:** Download an image from [https://unsplash.com/photos/a-group-of-birds-flying-over-a-body-of-water-J4-xolC4vGQ](https://unsplash.com/photos/a-group-of-birds-flying-over-a-body-of-water-J4-xolC4vGQ) and save it as `background.jpg` in the same directory as `index.html`.
    *   **Bird Chirp Sound:** Download the sound from [https://freesound.org/people/dibko/sounds/612725/](https://freesound.org/people/dibko/sounds/612725/) and save it as `bird-chirp.mp3` in the same directory as `index.html`.
2.  Open the `index.html` file in a web browser.
3.  Click the "Start" button to begin the quiz.
4.  Answer the questions by clicking on the options.
5.  If you answer correctly, you will hear a bird chirp.

## Prerequisites

You will need a modern web browser to play this game.
