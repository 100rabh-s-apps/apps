# India States Identification Game

This is a simple, interactive web-based game designed to help users learn and identify the states of India on a map.

## How to Play

1.  Open the `index.html` file in a web browser.
2.  The game will display the name of a state you need to find.
3.  Click or tap on the corresponding state on the map of India.
4.  The game will provide immediate feedback on your selection.
5.  If you are correct, the game will present you with a new state to find.
6.  Your progress is tracked, showing how many states you have correctly identified.
7.  If you get stuck, you can use the "Hint" button to highlight the correct state.
8.  You can restart the game at any time by clicking the "Restart Game" button.

## Features

-   **Interactive Map:** A clickable SVG map of India.
-   **Immediate Feedback:** Visual cues for correct and incorrect answers.
-   **Progress Tracking:** A counter for correctly identified states.
-   **Hint System:** A "Hint" button to help you find the correct state.
-   **Restart Functionality:** Start the game over at any time.
-   **Responsive Design:** The game is playable on both desktop and mobile devices.

## Technologies Used

-   **HTML:** The structure of the game.
-   **CSS:** Styling for the game, including the map and feedback messages.
-   **JavaScript:** The game's logic, including state management, user interaction, and feedback.

This project is self-contained in a single `index.html` file and does not require any external libraries or dependencies.
